# STALBLOCK Website v0.3 — Кубическая Зона + ПДА

Это веб-прототип сайта. Интерактивный ПДА (переключение вкладок и выбор меток карты) **работает только на сайте**, не подключён к игре или серверу. Его карта, сообщения, задания и показатели — демонстрационные. Никаких обещаний релиза или выдуманных реальных данных.

# STALBLOCK Website — v0.2 «Кубическая Зона»

Вторая концепция сайта: Minecraft + сталкерская Зона, блочный индустриальный мир, а не обычный неоновый sci-fi.

## Быстрый просмотр

Откройте `index.html` в браузере. Сайт полностью статический: HTML/CSS/JS, без сборщика, аккаунтов и внешнего JS. Нет внешних скриптов, шрифтов или CDN: используются системные шрифты. Основной арт нарисован в SVG и включён в исходники.

## Публикация и проверка в GitHub

1. Создайте отдельный репозиторий `STALBLOCK-Website` или выберите существующий репозиторий сайта.
2. Загрузите файлы из этой папки **в корень репозитория**. Убедитесь, что в коммите есть `index.html`, `styles.css`, `script.js` и каталог `assets/`.
3. В Settings → Pages включите Deploy from a branch, `main` / `(root)`. Если используется приватный репозиторий, убедитесь, что план GitHub поддерживает Pages.
4. Зафиксируйте точный SHA опубликованного коммита, затем откройте публичный адрес Pages в режиме инкогнито и с другого компьютера.
5. Проверьте меню, ссылки, FAQ, мобильную версию, отсутствие кнопки активной загрузки и ошибки консоли.
6. **Изменения локально не считаются проверенными**, пока не опубликованы и не проверены именно по публичному URL GitHub Pages.

При необходимости локальная быстрая проверка (не заменяет GitHub):

```bash
python scripts/check_site.py
python -m http.server 8000
```
